* Opening a frame

Once per document, =M-x beamer-gui-insert-preamble= adds or updates
the preamble lines the written code needs.  Then, with point in a
frame, =C-c M-g= (=beamer-gui-edit-frame=) compiles the frame and opens
it in the editor.  The key belongs to =beamer-gui-mode=.

The frame is compiled alone, with the document's preamble.  Note
options are turned off, so the window shows the slide only.

A message names what is missing: a =\documentclass= in the file,
which must hold both the frame and the preamble; a frame around
point; =pdflatex=; Python or its packages.  For a class other than
beamer, it asks before going on.  When LaTeX fails, its first error
is shown in Emacs and in the editor.

* In the editor

| Key or action     | Effect                                                     |
|-------------------+------------------------------------------------------------|
| drag              | move the element                                           |
| drag a handle     | resize; images keep their aspect ratio                     |
| =Ctrl=-click      | show the clicked text's source in Emacs                    |
| double-click      | the same; on a text shape, edit its text                   |
| =A= =E= =R= =T=   | add an arrow, ellipse, rectangle, text                     |
| =C-v=             | paste an image (saved in =fig_slides/=)                    |
| =B=               | background of the frame: colour, tint, image               |
| =S=               | snapping on or off                                         |
| right-click image | edit it in Inkscape or GIMP; saving it updates the slide   |
| =Del=             | delete the selected shapes                                 |
| =C-s=             | write the changes to the buffer and recompile              |

The elements of a frame are its environments, its =\includegraphics=
and =\movie=, and the preamble's commands that draw a picture, such
as a =\member= showing a photo and a name.  The preamble includes the
files it =\input=s.  An optional first argument that is a length, as
in =\begin{varblock}[0.5\textwidth]=, is the width, and resizing
changes it.  TikZ annotations of other text, such as =\tikzmark=, are
not elements.  =columns=, =center=, =minipage= and the overlay
environments are looked into, not moved; verbatim environments are
skipped.

The *Style* panel sets the colour, line width, dash, opacity, arrow
tips (=->=, =-latex=, =-stealth=, bars, single or double), bend, fill,
fill opacity and rounded corners of the selected shapes.  Its colours are those
the preamble defines, and the files it =\input=s, then the standard
named colours.

A dragged element snaps its edges and centre to those of other
elements and of the page, within 6 pixels.  A guide line shows the
alignment.

Clicking text moves Emacs to it in the source.  The word, its
neighbours and its element are looked up in the frame.  Text not
written literally in the source, such as maths, jumps to the nearest
word that is.

* Commands

| Command                      | Effect                                                    |
|------------------------------+-----------------------------------------------------------|
| =beamer-gui-edit-frame=      | open the frame at point in the editor                     |
| =beamer-gui-insert-preamble= | add or update the preamble lines                          |
| =beamer-gui-unwrap=          | put a moved element back in the text flow                 |
| =beamer-gui-label-frames=    | give every frame a =label=, from its title                |
| =beamer-gui-mode=            | minor mode with the =C-c M-g= key                         |

* Options

| Variable                            | Default                    |
|-------------------------------------+----------------------------|
| =beamer-gui-python=                 | =python3=                  |
| =beamer-gui-image-dir-name=         | =fig_slides=               |
| =beamer-gui-latex-command=          | =pdflatex= in batch mode   |
| =beamer-gui-container-environments= | looked into, not moved     |
| =beamer-gui-ignored-environments=   | skipped                    |
| =beamer-gui-inline-environments=    | set inside a line          |
| =beamer-gui-movable-macros=         | =includegraphics=, =movie= |
| =beamer-gui-image-editors=          | =inkscape=, =gimp=         |

To use another key:
#+begin_src elisp
(with-eval-after-load 'beamer-gui
  (keymap-set beamer-gui-mode-map "C-c g" #'beamer-gui-edit-frame))
#+end_src
