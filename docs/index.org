=beamer-gui= edits the frames of a LaTeX beamer presentation in a
graphical window started from Emacs.  Images, blocks, tcolorboxes,
lists, tables and textblocks are moved and resized with the mouse.
Arrows, ellipses, rectangles and text are added with the colours of
the document.

Each change is written to the LaTeX source, which is then compiled
again.  The code written is plain LaTeX between two comment lines
(see [[file:code.org][Code]]).

* Try it with =emacs -Q=

This does not touch your own Emacs configuration.

1. *Get beamer-gui.*
   #+begin_src bash
     git clone https://github.com/mathren/beamer-gui-emacs
     cd beamer-gui-emacs
   #+end_src

2. *A Python environment* with PySide6 and PyMuPDF, for the window:
   #+begin_src bash
     conda env create -f environment.yml
   #+end_src
   LaTeX (=pdflatex= with beamer, textpos and TikZ) comes from your TeX
   distribution.

3. *Open the sample deck.*
   #+begin_src bash
     BEAMER_GUI_PYTHON=$(conda run -n beamer-gui which python) emacs -Q -l quicktry.el
   #+end_src
   Point is in a frame: =M-x beamer-gui-edit-frame= opens it.

* Install

Emacs 30.1 or later, from the latest commit of =main=:

#+begin_src elisp
(use-package beamer-gui
  :vc (:url "https://github.com/mathren/beamer-gui-emacs"
       :branch "main"
       :rev :newest)
  :hook ((LaTeX-mode latex-mode) . beamer-gui-mode)
  :custom
  (beamer-gui-python "/path/to/envs/beamer-gui/bin/python3"))
#+end_src

=beamer-gui-python= is the interpreter printed by =conda run -n
beamer-gui which python=.  Update with =M-x package-vc-upgrade RET
beamer-gui=.
