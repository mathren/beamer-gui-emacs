The editor frames the code it writes or changes with two comment
lines.  It does not touch code outside them.  A save without changes
leaves the file unchanged.

* Shapes

#+begin_src latex
%%% beamer-gui arrow1
\begin{textblock*}{0.2\paperwidth}(0.4\paperwidth,0.4\paperheight)
  \tikz[x=\paperwidth,y=\paperheight]{\useasboundingbox (0,0) rectangle (0.2,-0.2); \draw[gui arrow, draw=Maroon, very thick, bend left=30] (0,-0) to (0.2,-0.2);}
\end{textblock*}
%%% ---
#+end_src

Positions are fractions of the page.  Colours and styles are TikZ
options; options added by hand are kept.  The base styles =gui arrow=,
=gui ellipse=, =gui rect= and =gui text= are in the preamble lines.

* Moved elements

An element of the text that is moved is wrapped, unchanged, in a
=textblock*=.  A spacer of its original size stays in its place, so the
rest of the slide does not move:

#+begin_src latex
%%% beamer-gui w1 (moved block)
\begin{textblock*}{0.9\paperwidth}(0.15\paperwidth,0.53\paperheight)
  \beamerguicontext{3pt}{0pt}% as in the text
  \begin{block}{A block}
    Block content.
  \end{block}
\end{textblock*}
\beamerguivspace{30.45pt}{0pt}{3pt}
%%% ---
#+end_src

=\beamerguicontext= gives the element the spacing it had in the text.
Resizing changes the =width=, =height= or =scale= of an image, or the
=width= of a tcolorbox, in the unit it was written in.
=M-x beamer-gui-unwrap= removes the wrapper and the spacer.

A moved =textblock= or =textblock*= keeps its own units, and gets the
comment lines.

* How positions are known

The frame is compiled twice in one document: once with invisible
markers recording where each element is (=\pdfsavepos=), once with the
elements hidden by =invisibleenv=, which keeps their space; this second
copy is the editor's background.  A last page holds a swatch of each
colour, read back for the palette.
